Introduction to C

What is C?

C is a general-purpose, procedural programming language. It is used to develop software, applications and system programs.

History of C

C was developed by Dennis Ritchie at Bell Labs.

Features of C

  • Simple and easy to learn
  • Fast and efficient
  • Portable
  • Structured programming language
  • Supports functions

Uses of C

  • Operating systems
  • Embedded systems
  • Software development
  • Game development
