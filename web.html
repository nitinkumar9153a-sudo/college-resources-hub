UNIT 1 • TOPIC 01

🌍 Introduction to Internet

Definition:

The Internet is a worldwide network of interconnected computers and devices that communicate and exchange information using standard communication protocols.

🔑 Features

  • It is a global network.
  • It connects millions of devices.
  • It allows information sharing.
  • It supports communication and online services.
  • TCP/IP is the main protocol suite.

💡 Applications

📧 Email

Electronic communication through the Internet.

🎓 Education

Online classes, courses and digital libraries.

🛒 E-Commerce

Online shopping and digital transactions.

🎮 Entertainment

Streaming, gaming, music and videos.

UNIT 1 • TOPIC 02

🌐 World Wide Web

Definition:

The World Wide Web is a system of interconnected web pages and resources that are accessed through the Internet using web browsers.

🌍 Internet

  • Global network.
  • Infrastructure for communication.
  • Supports many services.

🌐 WWW

  • Service running over Internet.
  • Uses web pages.
  • Accessed through browsers.
📝 Exam Point:

Internet is the network, whereas WWW is a service that operates over the Internet.

Image Tag:

Important Attributes

  • width: Image width.
  • height: Image height.
UNIT 2 • TOPIC 21

🗺️ Image Mapping

Definition:

Image mapping allows different areas of an image to act as separate clickable links. 

<img src="india-map.jpg"
     usemap="#india"
     width="600">

<map name="india">

    <area shape="rect"
          coords="182,211,229,221"
          href="haryana.html">

</map>
  • usemap: Connects image to map.
  • map: Defines image map.
  • area: Defines clickable region.
  • coords: Defines region coordinates.
UNIT 2 • TOPIC 22

🪟 Frames

Definition:

Frames were used in older HTML to divide the browser window into multiple sections, where different documents could be displayed.

Frames and the traditional frame-related elements are obsolete in modern HTML. Modern layouts use CSS and elements such as iframe when embedding another document is required. 

<iframe
    src="page.html"
    width="500"
    height="300">
</iframe>

UNIT 3 • TOPIC 01

🚀 Introduction to HTML5

Definition:

HTML5 is a modern version of HTML that provides improved semantic structure, multimedia support, graphics and modern web application features.

Major Features

  • Semantic elements.
  • Audio and video support.
  • Canvas graphics.
  • Web storage.
  • Improved forms.
UNIT 3 • TOPIC 02

✨ Advantages of HTML5

🎵 Multimedia

Audio and video can be embedded directly.

📱 Mobile Friendly

Supports modern responsive web development.

🎨 Graphics

Canvas supports drawing and graphics.

💾 Storage

Provides browser-based local storage features.

UNIT 3 • TOPIC 03

⚠️ Limitations of HTML4

  • Limited native multimedia support.
  • Required external plugins for some media.
  • Limited semantic elements.
  • No built-in canvas element.
  • Less support for modern web application features.

UNIT 4 • 6 HOURS

🎨 CSS — Cascading Style Sheets

Styling, layouts, colors, fonts, boxes, columns, positioning, floating, lists and tables.

UNIT 4 • TOPIC 01

🎨 CSS and Style Sheets

Definition:

CSS stands for Cascading Style Sheets. It is used to control the presentation, appearance and layout of HTML documents.

Benefits

  • Controls colors and fonts.
  • Controls spacing and layout.
  • Creates responsive designs.
  • Separates content from presentation.
  • Allows reuse of styles.
UNIT 4 • TOPIC 02

📝 Text Formatting using CSS

p {
    color: blue;
    font-size: 18px;
    text-align: center;
}

h1 {
    text-transform: uppercase;
}
UNIT 4 • TOPIC 03

📌 Embedded CSS

Embedded CSS is written inside the style element within the head section of an HTML document. 

<style>

p {
    color: blue;
    font-size: 18px;
}

</style>
UNIT 4 • TOPIC 04

📍 Inline CSS

Inline CSS is written directly inside the style attribute of an HTML element. 

<p style="color: blue;">
    Hello World
</p>
UNIT 4 • TOPIC 05

📁 External CSS

External CSS is stored in a separate .css file and connected to the HTML document. 

<link rel="stylesheet"
      href="style.css">
⭐ Important:

External CSS is useful when the same styling needs to be applied to multiple webpages.
