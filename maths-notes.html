Unit I

📊 MATRICES

Rank, Elementary Transformations, Inverse, Normal Form, Consistency, Eigenvalues, Eigenvectors and Cayley-Hamilton Theorem.

01

Types of Matrices

A matrix is a rectangular arrangement of numbers written in rows and columns.

A = [ aᵢⱼ ]ₘₓₙ

Important Types

  • Row Matrix: Only one row.
  • Column Matrix: Only one column.
  • Square Matrix: Number of rows = number of columns.
  • Zero Matrix: All elements are zero.
  • Identity Matrix: Main diagonal elements are 1 and remaining elements are 0.
  • Diagonal Matrix: All elements outside the main diagonal are zero.
  • Symmetric Matrix: Aᵀ = A.
  • Skew-Symmetric Matrix: Aᵀ = −A.
02

Rank of a Matrix

The rank of a matrix is the maximum number of linearly independent rows or columns.

Method

  1. Write the given matrix.
  2. Apply elementary row operations.
  3. Convert it into echelon form.
  4. Count the number of non-zero rows.
Rank(A) = Number of non-zero rows in echelon form
✍️ Solved Example
A = [ 1 2 3 2 4 6 1 1 1 ]
R₂ → R₂ − 2R₁
R₃ → R₃ − R₁
[ 1 2 3 0 0 0 0 -1 -2 ]
There are 2 non-zero rows.
Therefore Rank(A) = 2.
🎯 Exam Tip: Row operations ko clearly show karo. Sirf final rank likhne par complete marks miss ho sakte hain.
03

Gauss-Jordan Method for Inverse

Gauss-Jordan method se square matrix ka inverse elementary row operations ke through find kiya jata hai.

Basic Idea

[ A | I ] → [ I | A⁻¹ ]

Steps

  1. Matrix A ke saath identity matrix attach karo.
  2. Elementary row operations apply karo.
  3. Left side ko identity matrix banao.
  4. Right side automatically A⁻¹ ban jayega.
✍️ Solved Example
A = [ 2 1 1 1 ]
[ A | I ] [ 2 1 | 1 0 1 1 | 0 1 ] → [ 1 0 | 1 -1 0 1 | -1 2 ]
Therefore,
A⁻¹ = [ 1 -1 -1 2 ]
04

Normal Form of a Matrix

Elementary row and column transformations ki help se matrix ko standard form mein convert kiya jata hai.

Normal Form = [ Iᵣ 0 0 0 ]

Yahan r matrix ka rank represent karta hai.

Example
Rank = 2 Normal Form = [ 1 0 0 0 1 0 0 0 0 ]
05

Consistency of Linear Equations

Linear equations ka system consistent hai agar uska at least one solution exist karta hai.

Consistent ⇔ Rank(A) = Rank([A|B])

Three Cases

  • Rank(A) = Rank([A|B]) = n → Unique solution
  • Rank(A) = Rank([A|B]) < n → Infinitely many solutions
  • Rank(A) ≠ Rank([A|B]) → No solution / inconsistent
✍️ Solved Example
x + y = 5 x − y = 1
Add both equations:
2x = 6
Therefore x = 3.
Substitute x = 3:
3 + y = 5 y = 2
Solution = (3,2)
06

Eigenvalues

Eigenvalue λ woh scalar value hai jiske liye non-zero vector X satisfy karta hai:

AX = λX

Rearranging:

(A − λI)X = 0

Non-zero solution ke liye:

|A − λI| = 0
✍️ Solved Example
A = [ 2 1 1 2 ]
|2−λ 1 | | 1 2−λ| = 0 (2−λ)² − 1 = 0 λ² − 4λ + 3 = 0 (λ−1)(λ−3)=0
Eigenvalues: λ = 1, 3
07

Eigenvectors

Eigenvalue find karne ke baad corresponding eigenvector find kiya jata hai.

(A − λI)X = 0

Procedure

  1. Characteristic equation solve karo.
  2. Eigenvalue λ select karo.
  3. (A−λI)X=0 likho.
  4. Equations solve karke X find karo.
08

Cayley-Hamilton Theorem

Every square matrix satisfies its own characteristic equation.

If p(λ)=0 is characteristic equation, then p(A)=0.
✍️ Example
Characteristic equation: λ² − 4λ + 3 = 0 Replace λ by A: A² − 4A + 3I = 0
This is the Cayley-Hamilton identity.
🎯 Important: Cayley-Hamilton se A², A³ ya A⁻¹ bhi find karne wale questions aa sakte hain.
Unit II

∫ CALCULUS

Rolle's Theorem, Lagrange MVT, Taylor-Maclaurin, Curvature, L'Hospital Rule and Beta-Gamma Functions.

01

Rolle's Theorem

Statement

If f(x) is continuous on [a,b], differentiable on (a,b), and f(a)=f(b), then there exists at least one c∈(a,b) such that:

f′(c) = 0

Conditions

  • Continuous on [a,b]
  • Differentiable on (a,b)
  • f(a)=f(b)
✍️ Solved Example
f(x)=x²−4x+3 Interval [1,3]
f(1)=1−4+3=0
f(3)=9−12+3=0
Therefore f(1)=f(3).
f′(x)=2x−4 f′(c)=0 2c−4=0 c=2
Since 2 lies between 1 and 3, Rolle's theorem is verified.
02

Lagrange Mean Value Theorem

If f is continuous on [a,b] and differentiable on (a,b), then there exists c∈(a,b) such that:

f′(c) = [ f(b) − f(a) ] / (b − a)
✍️ Solved Example
f(x)=x² [1,3]
[f(3)-f(1)]/(3-1) = (9−1)/2 = 4
f′(x)=2x 2c=4 c=2
03

Taylor Series

Taylor series kisi function ko x=a ke around infinite polynomial terms ke form mein represent karti hai.

f(x) = f(a) + (x−a)f′(a) + (x−a)²/2! f″(a) + ...

Important

Taylor series ka centre x=a hota hai.

04

Maclaurin Series

Maclaurin series Taylor series ka special case hai jahan a=0.

f(x)= f(0) + xf′(0) + x²/2! f″(0) + ...

Must Remember Expansions

eˣ = 1 + x + x²/2! + x³/3! + ... sin x = x − x³/3! + x⁵/5! − ... cos x = 1 − x²/2! + x⁴/4! − ... ln(1+x) = x − x²/2 + x³/3 − ...
✍️ Example: eˣ

Since every derivative of eˣ is eˣ and its value at x=0 is 1:

eˣ = 1+x+x²/2!+x³/3!+...
05

Curvature

Curvature batata hai ki curve kitni rapidly bend ho raha hai.

K = |d²y/dx²| / [1+(dy/dx)²]³ᐟ²

Example

y=x² y′=2x y″=2 Therefore: K = 2/[1+4x²]³ᐟ²
06

Radius of Curvature

ρ = [1+(dy/dx)²]³ᐟ² / |d²y/dx²|
✍️ Example
y=x² y′=2x y″=2 ρ = [1+4x²]³ᐟ² / 2
07

L'Hospital's Rule

Indeterminate forms 0/0 and ∞/∞ ke limits ko solve karne ke liye L'Hospital rule use hota hai.

lim f(x)/g(x) = lim f′(x)/g′(x)
✍️ Example
lim(x→0) sin x/x = lim(x→0) cos x/1 = 1
08

Beta Function

B(m,n) = ∫₀¹ xᵐ⁻¹(1−x)ⁿ⁻¹ dx

Important Properties

  • B(m,n)=B(n,m)
  • B(m,n)=Γ(m)Γ(n)/Γ(m+n)
09

Gamma Function

Γ(n) = ∫₀∞ e⁻ˣ xⁿ⁻¹ dx
Γ(n)=(n−1)!
✍️ Example
Γ(5) = (5−1)! = 4! = 24
Unit III

🌐 MULTIVARIABLE CALCULUS

Limits, Continuity, Partial Derivatives, Euler's Theorem, Maxima-Minima and Vector Calculus.

01

Limit of a Function

Limit batata hai ki x kisi value ke close jaane par function kis value ke close jaata hai.

✍️ Example
lim(x→2)(x²+3) = 2²+3 = 7
02

Continuity

Function f(x), x=a par continuous hai agar:

lim(x→a) f(x) = f(a)

Three Conditions

  • f(a) exists.
  • lim(x→a) f(x) exists.
  • Both are equal.
03

Partial Derivatives

Multiple variables wale function mein ek variable ke respect mein differentiation karte waqt baaki variables ko constant maana jata hai.

✍️ Solved Example
z=x²y+3xy²
∂z/∂x = 2xy+3y² ∂z/∂y = x²+6xy
04

Homogeneous Function

Agar:

f(tx,ty)=tⁿf(x,y)

then function degree n ka homogeneous function hai.

Example
f(x,y)=x²+xy+y² f(tx,ty) = t²(x²+xy+y²) Therefore degree = 2
05

Euler's Theorem

If z is homogeneous of degree n:

x(∂z/∂x) + y(∂z/∂y) = nz
✍️ Example
z=x²+xy+y² zx=2x+y zy=x+2y xzx+yzy = x(2x+y)+y(x+2y) = 2x²+2xy+2y² = 2z
06

Total Derivative

Jab x aur y dono kisi third variable ke functions hon, tab chain rule ka use karke total derivative find karte hain.

dz/dt = (∂z/∂x)(dx/dt) + (∂z/∂y)(dy/dt)
✍️ Example
z=x²+y² x=t y=t² dz/dt =2x(1)+2y(2t) =2t+4t³
07

Maxima and Minima of Two Variables

Step 1

fx = 0 fy = 0

Critical points find karo.

Step 2

D = fxx fyy − (fxy)²
  • D > 0 and fxx > 0 → Minimum
  • D > 0 and fxx < 0 → Maximum
  • D < 0 → Saddle Point
  • D = 0 → Test inconclusive
✍️ Example
f=x²+y² fx=2x=0 → x=0 fy=2y=0 → y=0

Since x²+y² ≥ 0 for all real x,y, (0,0) is a minimum point.

08

Lagrange Multipliers

Constraint ke saath maxima/minima find karne ke liye Lagrange multiplier method use hota hai.

∇f = λ∇g

Procedure

  1. ∇f calculate karo.
  2. ∇g calculate karo.
  3. ∇f = λ∇g set karo.
  4. Constraint g=0 use karo.
  5. Unknowns solve karo.
09

Gradient

Gradient scalar function ke maximum increase ki direction batata hai.

∇φ = i(∂φ/∂x) + j(∂φ/∂y) + k(∂φ/∂z)
Example
φ=x²+y²+z² ∇φ=2xi+2yj+2zk
10

Directional Derivative

Kisi particular direction mein function ke rate of change ko directional derivative kehte hain.

Dᵤφ = ∇φ · u

Yahan u unit vector hona chahiye.

11

Divergence

Vector field ke outward flow/source strength ko divergence describe karta hai.

For F = Pi + Qj + Rk: ∇·F = ∂P/∂x + ∂Q/∂y + ∂R/∂z
✍️ Example
F=xi+yj+zk ∇·F = 1+1+1 = 3
12

Curl

Curl vector field ki rotational tendency ko represent karta hai.

∇×F = | i j k | | ∂x ∂y ∂z | | P Q R |

Agar curl zero ho, field ko appropriate region mein irrotational kaha ja sakta hai.

Unit IV

∞ SEQUENCES, SERIES & FOURIER

Convergence Tests, Alternating Series, Absolute/Conditional Convergence and Fourier Series.

01

Sequence

Sequence numbers ka ordered collection hota hai:

a₁, a₂, a₃, a₄, ...
Example
1, 2, 3, 4, 5, ...
02

Convergence of Sequence

Agar n → ∞ par sequence ek finite value approach kare, to sequence convergent hai.

aₙ = 1/n lim(n→∞) 1/n = 0
Therefore sequence converges to 0.
03

Comparison Test

Kisi difficult positive-term series ko known series se compare kiya jata hai.

0 ≤ aₙ ≤ bₙ

Agar Σbₙ convergent hai, then Σaₙ bhi convergent hai.

04

Ratio Test

L = lim(n→∞) |aₙ₊₁ / aₙ|
  • L < 1 → Convergent
  • L > 1 → Divergent
  • L = 1 → Inconclusive
✍️ Example
Σ 1/n! aₙ = 1/n! aₙ₊₁ = 1/(n+1)! |aₙ₊₁/aₙ| = 1/(n+1) L=0
Since L<1, series is convergent.
05

Raabe's Test

R = lim(n→∞) n[ (aₙ/aₙ₊₁) − 1 ]
  • R > 1 → Convergent
  • R < 1 → Divergent
  • R = 1 → Inconclusive
06

Logarithmic Test

Positive-term series ki convergence ko logarithmic behaviour ke through study karne ke liye logarithmic test use kiya jata hai.

🎯 Exam mein test ka exact criterion question mein diye syllabus/teacher convention ke according apply karo.
07

Cauchy's Root Test

L = lim(n→∞) ⁿ√|aₙ|
  • L < 1 → Convergent
  • L > 1 → Divergent
  • L = 1 → Inconclusive
✍️ Example
Σ(1/2)ⁿ ⁿ√|aₙ| = 1/2 L = 1/2 < 1 Therefore convergent.
08

Alternating Series

Jis series mein consecutive terms ke signs alternate hote hain, use alternating series kehte hain.

1 − 1/2 + 1/3 − 1/4 + ...
09

Leibniz Test

Alternating series:

Σ(−1)ⁿ aₙ

converges if:

  • aₙ positive hai.
  • aₙ decreasing hai.
  • lim aₙ = 0.
10

Absolute and Conditional Convergence

Absolute Convergence

Agar:

Σ|aₙ|

convergent hai, to original series absolutely convergent hai.

Conditional Convergence

Original series convergent ho lekin absolute series divergent ho, to conditional convergence hoti hai.

Example
1 − 1/2 + 1/3 − 1/4 + ... → Conditionally convergent
11

Fourier Series

Fourier series kisi periodic function ko sine aur cosine terms ke sum ke form mein represent karti hai.

f(x) = a₀/2 + Σ[ aₙcos(nx) + bₙsin(nx) ]
12

Euler's Formulae for Fourier Series

a₀ = (1/π) ∫₋π^π f(x) dx aₙ = (1/π) ∫₋π^π f(x)cos(nx) dx bₙ = (1/π) ∫₋π^π f(x)sin(nx) dx
🎯 Fourier question mein sabse pehle interval aur function ki even/odd nature check karo.
13

Even and Odd Functions

Even Function

f(−x)=f(x)

Example: x²

Even Fourier function ke liye:

bₙ = 0

Odd Function

f(−x)=−f(x)

Example: x³

a₀=0 aₙ=0
14

Half-Range Fourier Series

Jab function sirf half interval mein given ho, tab half-range Fourier series use hoti hai.

Types

  • Half-range sine series
  • Half-range cosine series

Question ki boundary condition ke according sine ya cosine expansion choose ki jati hai.

15

Fourier Series on (−L,L)

Jab interval (−π,π) ke instead (−L,L) ho, Fourier terms modify ho jate hain.

f(x)= a₀/2 + Σ[ aₙcos(nπx/L) + bₙsin(nπx/L) ]

  • Theorem question mein Statement + Conditions + Formula + Verification likho.

  • Taylor/Maclaurin mein standard expansion yaad rakho.

  • Series question mein test ka naam pehle likho.
  • Fourier mein even/odd property check karna mat bhoolna.
  • Formula ke baad substitution aur final answer clearly highlight karo.
