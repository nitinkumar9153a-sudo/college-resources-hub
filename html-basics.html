HTML Basics

What is HTML?

HTML stands for HyperText Markup Language. It is used to create and structure web pages.

HTML Tags

HTML tags are keywords written inside angle brackets < >.

Basic HTML Structure

<html>
<head>
    <title>My Website</title>
</head>
<body>
    My Web Page
</body>
</html>

Important HTML Tags

  • <h1> - Heading
  • <p> - Paragraph
  • <br> - Line break
  • <b> - Bold text
  • <i> - Italic text
  • <u> - Underlined text
  • <img> - Image
  • <a> - Hyperlink

Attributes

Attributes provide additional information about an HTML tag.

Example: <img src="student.jpg" width="200">
