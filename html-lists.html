HTML Lists

What is a List?

An HTML list is used to display items in an organized way.

1. Ordered List

An ordered list displays items with numbers.

Example:

  1. HTML
  2. CSS
  3. JavaScript

2. Unordered List

An unordered list displays items with bullets.

Example:

  • Mathematics
  • Physics
  • C Programming

3. List Item

The <li> tag is used to define an item inside a list.

Important Tags

  • <ol> - Ordered List
  • <ul> - Unordered List
  • <li> - List Item
