Flowchart

What is a Flowchart?

A flowchart is a graphical representation of an algorithm. It uses different symbols to show the steps of a problem.

Common Flowchart Symbols

  • Oval: Start / Stop
  • Rectangle: Process / Calculation
  • Parallelogram: Input / Output
  • Diamond: Decision
  • Arrow: Flow of control

Example: Even or Odd

  1. Start
  2. Input N
  3. Check N % 2 == 0
  4. If Yes → Print Even
  5. If No → Print Odd
  6. Stop
