Algorithm

What is an Algorithm?

An algorithm is a step-by-step procedure used to solve a particular problem.

Characteristics of an Algorithm

  • It should have a clear beginning and end.
  • Each step should be clear and definite.
  • It should produce a result.
  • Steps should be arranged in a proper sequence.

Example: Add Two Numbers

  1. Start
  2. Input two numbers A and B
  3. Calculate Sum = A + B
  4. Display Sum
  5. Stop
