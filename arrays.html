Arrays in C

What is an Array?

An array is a collection of elements of the same data type stored in continuous memory locations.

Syntax

data_type array_name[size];

Example

int marks[5];

Example with Values

int marks[5] = {80, 75, 90, 85, 88};

Important Point

Array indexing starts from 0. For example, the first element is marks[0].
