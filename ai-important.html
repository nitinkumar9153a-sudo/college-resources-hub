🧠 UNIT 1 — Foundations of Artificial Intelligence

AI basics, types, domains and intelligent systems

QUESTION 01 ⭐ 2–6 Marks

What is Artificial Intelligence (AI)?

📌 Definition
Artificial Intelligence (AI) is a branch of computer science that develops systems capable of performing tasks that normally require human intelligence.

AI enables computers or machines to perform activities such as learning, reasoning, problem solving, decision making, perception and language understanding.

Main abilities of AI:

  • Learning from data and experience
  • Reasoning and logical thinking
  • Solving complex problems
  • Understanding natural language
  • Recognising images, speech and patterns
  • Making decisions
💡 Examples
Chatbots, voice assistants, recommendation systems, face recognition, autonomous vehicles and medical diagnosis systems.
Exam Point: AI = Making machines capable of performing tasks that require human-like intelligence.
QUESTION 02 ⭐ 3–5 Marks

What are the types of Artificial Intelligence?

AI can be classified according to its capability into the following types:

Type Meaning Example / Status
Narrow AI Designed to perform a specific task or a limited range of tasks. Voice assistants, recommendation systems
General AI Theoretical AI capable of performing a wide range of intellectual tasks similar to humans. Not achieved yet
Super AI Hypothetical AI that would exceed human intelligence in many areas. Future / hypothetical concept
Remember: Narrow AI exists in practical applications. General AI and Super AI are theoretical concepts.

🔎 UNIT 2 — Searching & Knowledge Representation

BFS, DFS, heuristic search and representation of knowledge

QUESTION 09 ⭐ 5–6 Marks

What is Breadth First Search (BFS)?

📌 Definition
Breadth First Search is an uninformed search algorithm that explores a search tree or graph level by level.

BFS normally uses a Queue data structure. It first visits the starting node, then all its neighbouring nodes, and continues level by level. 

                A
              /   \
             B     C
            / \   / \
           D   E F   G

         BFS Traversal:
         A → B → C → D → E → F → G

Important points:

  • Uses Queue
  • Works level by level
  • Complete under standard finite-branching assumptions
  • Can find the shallowest solution when each step has equal cost
Remember: BFS → Breadth → Queue → Level by Level.
QUESTION 10 ⭐ 5–6 Marks

What is Depth First Search (DFS)?

📌 Definition
Depth First Search is an uninformed search algorithm that explores one branch as deeply as possible before backtracking.

DFS can be implemented using a Stack or recursion. 

                A
              /   \
             B     C
            / \   / \
           D   E F   G

         One possible DFS:
         A → B → D → E → C → F → G

Important points:

  • Uses Stack / Recursion
  • Explores deeply before backtracking
  • Uses less memory than BFS in many cases
  • May get stuck following a deep path in an infinite search space
Remember: DFS → Depth → Stack → Deep first.
QUESTION 11 ⭐ 3–5 Marks

What is Heuristic Search?

📌 Definition
Heuristic search uses additional problem-specific knowledge to guide the search toward a promising solution.

This additional knowledge is represented by a heuristic function, commonly written as h(n).

Current State
→
Evaluate h(n)
→
Choose Promising State
→
Solution
💡 Example
In a route-finding problem, estimated distance to the destination can help the system choose a promising route.

Common heuristic-based approaches include Greedy Best-First Search and A*.

🧑‍💻 UNIT 3 — Expert Systems

Concept, architecture, components and knowledge acquisition

QUESTION 13 ⭐ 5–6 Marks

What is an Expert System?

📌 Definition
An Expert System is an AI-based computer system that uses stored knowledge and reasoning techniques to solve problems in a specific domain in a manner similar to a human expert.

Main components:

  • Knowledge Base: Stores facts and rules.
  • Inference Engine: Applies rules to the available facts.
  • User Interface: Provides communication with the user.
  • Working Memory: Stores information about the current problem.
💡 Example
A medical expert system can use symptoms and medical knowledge to assist in identifying possible diseases.

QUESTION 15 ⭐ 5–6 Marks

What is Knowledge Acquisition?

📌 Definition
Knowledge Acquisition is the process of collecting, organising and transferring knowledge from experts, documents, databases or other sources into a form that an AI system can use.

Common methods:

  1. Expert interviews
  2. Observation
  3. Questionnaires
  4. Document analysis
  5. Database and data analysis
  6. Case studies
Important: Knowledge acquisition is often difficult because experts may have knowledge based on experience that is difficult to express explicitly.

QUESTION 16 ⭐ 3–5 Marks

What is Classification in Machine Learning?

📌 Definition
Classification is a supervised learning technique used to assign an input to one of several predefined classes.
💡 Examples
  • Email → Spam / Not Spam
  • Medical report → Disease / No Disease
  • Image → Cat / Dog

QUESTION 17 ⭐ 3–5 Marks

What is Regression in Machine Learning?

📌 Definition
Regression is a supervised learning technique used to predict a continuous numerical value.
💡 Examples
  • Predicting house prices
  • Predicting temperature
  • Predicting sales
  • Predicting monthly revenue

In simple words, classification predicts a category, while regression predicts a number/value.

QUESTION 19 ⭐ 5–6 Marks

What is Reinforcement Learning?

📌 Definition
Reinforcement Learning is a type of Machine Learning in which an agent learns by interacting with an environment and receiving rewards or penalties for its actions. 
                   ┌──────────────┐
                   │   AGENT      │
                   └──────┬───────┘
                          │
                       ACTION
                          ↓
                   ┌──────────────┐
                   │ ENVIRONMENT  │
                   └──────┬───────┘
                          │
                 STATE + REWARD
                          │
                          └──────→ AGENT

Important terms:

  • Agent: Learner or decision maker.
  • Environment: World in which the agent operates.
  • Action: Decision taken by the agent.
  • Reward: Feedback received after an action.
  • Policy: Strategy used to select actions.
💡 Example
A game-playing AI can learn which actions lead to winning by receiving positive or negative rewards.

📌 Main Steps
  1. Data Collection: Gather relevant data for the problem.
  2. Data Preparation: Clean and prepare the data for training.
  3. Feature Selection: Select useful information/features when required.
  4. Model Selection: Choose a suitable ML algorithm or model.
  5. Training: Train the model using available training data.
  6. Testing: Test the model on data not used for training.
  7. Evaluation: Measure how well the model performs.
  8. Deployment: Put the trained model into practical use.

🔥 EXTRA — Must Remember Comparisons

These short comparisons are useful for 3–5 mark questions.

⭐ BFS vs DFS

BFS DFS
Explores level by level. Explores depth first.
Uses Queue. Uses Stack / Recursion.
Usually requires more memory. Usually requires less memory for deep sparse searches.
Finds shallowest solution under standard equal-cost conditions. Does not generally guarantee the shallowest solution.

⭐ Classification vs Regression vs Clustering

Classification Regression Clustering
Predicts categories. Predicts numerical values. Creates groups.
Supervised. Supervised. Unsupervised.
Example: Spam / Not Spam. Example: House price. Example: Customer groups.
