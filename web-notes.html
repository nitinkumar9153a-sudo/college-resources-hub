UNIT 1

🌐 Internet & World Wide Web

Internet: Internet is a worldwide network of interconnected computers and devices that communicate with each other using standard communication protocols.

1.1 What is the Internet?

The Internet is a global network that connects millions of computers, smartphones, servers and other devices. It allows users to share information and communicate from different locations.

Major Uses of Internet

  • Communication through email and messaging
  • Online education
  • Online banking
  • E-commerce and shopping
  • Entertainment and streaming
  • Social networking
  • Cloud computing
  • Information searching

1.2 What is the World Wide Web?

World Wide Web (WWW): WWW is a collection of interconnected web pages and resources that can be accessed through the Internet using web browsers.

The Web uses technologies such as HTML, HTTP, URLs and web browsers to provide information to users.

1.3 Internet vs WWW

Internet World Wide Web
Global network of connected devices. Collection of websites and web pages.
Infrastructure/network. Service running over the Internet.
Includes email, FTP, web etc. Mainly uses web pages and web resources.

1.4 Web Browser

Web Browser: A software application used to access and display web pages on the Internet.

Examples

  • Google Chrome
  • Microsoft Edge
  • Mozilla Firefox
  • Safari
  • Opera

1.5 Web Server

Web Server: A computer or software that stores and delivers websites and web resources to clients through the Internet.

1.6 HTTP

HTTP: HTTP stands for HyperText Transfer Protocol. It is used for communication between web browsers and web servers.

When a user enters a website address, the browser sends an HTTP request to the server. The server processes the request and sends an HTTP response.

Example:
When you open a website, the browser requests the required web page from the server and the server sends the page back to the browser.

1.7 Web Searching Techniques

  • Use specific keywords.
  • Use quotation marks for exact phrases.
  • Use relevant keywords instead of long sentences.
  • Check multiple reliable sources.
  • Use advanced search filters when required.
Exam Point: Internet is the global network, whereas WWW is a service that works over the Internet and provides interconnected web pages.
UNIT 2

🏗️ Basics of HTML

HTML: HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure web pages.

2.1 Features of HTML

  • Easy to learn and use.
  • Platform independent.
  • Supports multimedia.
  • Used to create web page structure.
  • Works with CSS and JavaScript.
  • Supported by all modern browsers.

2.2 Basic Structure of HTML

<!DOCTYPE html> <html> <head> <title>My Web Page</title> </head> <body> <h1>Hello World</h1> <p>Welcome to my website.</p> </body> </html>

2.3 Important HTML Tags

Tag Purpose
<html> Defines HTML document.
<head> Contains document information.
<title> Defines page title.
<body> Contains visible page content.
<h1> to <h6> Defines headings.
<p> Defines paragraph.
<a> Creates hyperlink.
<img> Displays an image.
<br> Creates line break.

2.4 HTML Lists

Ordered List

<ol> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ol>

Unordered List

<ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul>

2.5 Hyperlinks

The anchor tag is used to create hyperlinks between web pages.

<a href="https://example.com"> Visit Website </a>

2.6 Images

The <img> tag is used to insert an image into an HTML page.

<img src="image.jpg" alt="My Image" width="300">

2.7 Static and Dynamic Websites

Static Website Dynamic Website
Content usually remains fixed. Content can change dynamically.
Usually simpler. Usually more complex.
Mostly HTML/CSS. May use server-side programming and databases.
Exam Point: HTML provides the structure of a webpage. CSS provides styling and JavaScript provides behavior and interactivity.
UNIT 3

🚀 HTML5

HTML5: HTML5 is the modern version of HTML that provides improved semantic elements, multimedia support, graphics, storage and advanced form features.

3.1 Advantages of HTML5

  • Supports audio and video without external plugins.
  • Provides semantic elements.
  • Supports graphics using Canvas and SVG.
  • Provides web storage.
  • Improves form controls.
  • Supports modern web applications.

3.2 HTML5 Semantic Elements

Element Purpose
<header> Defines header section.
<nav> Defines navigation links.
<section> Defines a section of content.
<article> Defines independent content.
<aside> Defines side content.
<footer> Defines footer section.

3.3 Audio

HTML5 provides the <audio> element for playing audio directly in a web page.

<audio controls> <source src="song.mp3" type="audio/mpeg"> </audio>

3.4 Video

<video width="500" controls> <source src="video.mp4" type="video/mp4"> </video>

3.5 Canvas

Canvas: The HTML5 Canvas element provides an area where graphics can be drawn using JavaScript.
<canvas id="myCanvas" width="300" height="150"> </canvas>

3.6 Web Storage

Web Storage allows websites to store data in the user's browser.

  • localStorage: Data remains stored until manually removed.
  • sessionStorage: Data normally remains only for the current session.

3.7 HTML5 Forms

HTML5 introduced new input types that make forms easier and more user-friendly.

Input Type Use
email Email address
number Numeric values
date Date selection
range Range/slider
color Color selection
Exam Point: HTML5 is important because it introduced semantic elements, multimedia, graphics, web storage and improved form controls.
UNIT 4

🎨 CSS – Cascading Style Sheets

CSS: CSS stands for Cascading Style Sheets. It is used to control the appearance, layout and presentation of HTML elements.

4.1 Why CSS is Used?

  • Changes colors and backgrounds.
  • Controls fonts and text.
  • Creates layouts.
  • Controls spacing and borders.
  • Improves website appearance.
  • Helps create responsive designs.

4.2 Types of CSS

1. Inline CSS

CSS written directly inside an HTML element.

<p style="color: blue;"> Hello World </p>

2. Internal CSS

CSS written inside the <style> element in the HTML document.

<style> p { color: blue; } </style>

3. External CSS

CSS is written in a separate .css file and linked with HTML.

<link rel="stylesheet" href="style.css">

4.3 CSS Selectors

Selector Example Purpose
Element p Selects all paragraph elements.
Class .box Selects elements with class box.
ID #header Selects element with specific ID.

4.4 Text Formatting

p { color: blue; font-size: 18px; text-align: center; font-family: Arial; }

4.5 Background

body { background-color: lightblue; } .box { background-image: url("image.jpg"); }

4.6 CSS Box Model

The CSS box model describes how every HTML element is treated as a rectangular box.

  • Content – actual content
  • Padding – space around content
  • Border – boundary around padding
  • Margin – outer space around element
Box Model Order
Content → Padding → Border → Margin

4.7 CSS Positioning

CSS position property controls how an element is positioned on a webpage.

  • static
  • relative
  • absolute
  • fixed
  • sticky

4.8 Display Property

  • block
  • inline
  • inline-block
  • none
  • flex
  • grid

4.9 CSS Float

The float property is used to move an element to the left or right and allow other content to wrap around it.

img { float: left; margin-right: 15px; }

4.10 CSS Tables

table { width: 100%; border-collapse: collapse; } td, th { border: 1px solid black; padding: 10px; }
Exam Point: CSS is responsible for the presentation and styling of HTML documents. The three main types are Inline, Internal and External CSS.
