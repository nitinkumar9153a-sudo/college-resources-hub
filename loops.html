Loops in C

What is a Loop?

A loop is used to repeat a block of statements multiple times until a condition is satisfied.

Types of Loops

  • for loop
  • while loop
  • do-while loop

for Loop

The for loop is used when the number of repetitions is known.

for (int i = 1; i <= 5; i++)
    printf("%d ", i);

while Loop

The while loop runs as long as the condition is true.

while (i <= 5)
    printf("%d ", i);

do-while Loop

The do-while loop executes the statements at least once.

do {
    printf("%d ", i);
} while (i <= 5);
