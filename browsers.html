Web Browsers and Servers

What is a Web Browser?

A web browser is a software application used to access and view websites on the Internet.

Examples of Web Browsers

  • Google Chrome
  • Microsoft Edge
  • Mozilla Firefox
  • Safari

What is a Web Server?

A web server is a computer or software that stores and delivers web pages to users when requested.

Browser and Server

The browser sends a request to the server. The server processes the request and sends the required web page back to the browser.
