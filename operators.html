Operators in C

What is an Operator?

An operator is a symbol used to perform an operation on one or more values.

Types of Operators

  • Arithmetic: +, -, *, /, %
  • Relational: >, <, ==, !=, >=, <=
  • Logical: &&, ||, !
  • Assignment: =, +=, -=, *=, /=
  • Increment/Decrement: ++, --
  • Bitwise: &, |, ^, ~, <<, >>

Example

int a = 10;
int b = 5;
int sum = a + b;
