UNIT 1

Programming Fundamentals and Problem Solving

Computational and Problem Solving using C | B.Tech CSE – 1st Semester

SLIDE 01

🧠 What is Problem Solving?

Problem solving is the process of understanding a problem, developing a logical solution and implementing that solution using a programming language.

Simple Definition: Problem solving means finding a correct and efficient way to solve a given problem.

Basic Steps of Problem Solving

  1. Understand the problem.
  2. Identify the required input.
  3. Identify the expected output.
  4. Design the algorithm.
  5. Prepare flowchart or pseudocode.
  6. Write the program.
  7. Compile and execute.
  8. Test the program.
  9. Debug errors.
SLIDE 02

💻 Computational Problem

A computational problem is a problem that can be solved using a computer by following a sequence of logical steps.

Examples

  • Finding the largest of three numbers.
  • Calculating the average marks of students.
  • Finding factorial of a number.
  • Checking whether a number is even or odd.
  • Sorting numbers in ascending order.
Example Problem

Find the largest among three numbers A, B and C.

Input: A, B and C

Output: Largest number

SLIDE 03

🔢 Programming Logic

Logic is a systematic way of thinking used to solve a problem. Programming logic defines the sequence of instructions that a computer must follow.

Three Basic Logical Structures

Structure Meaning Example
Sequence Statements execute one after another. Input → Calculate → Output
Selection Decision is made based on a condition. if-else
Iteration Statements are repeated. for / while
SLIDE 04

📋 Algorithm

An algorithm is a finite sequence of well-defined steps used to solve a particular problem.

Characteristics of an Algorithm

  • Input: It may accept zero or more inputs.
  • Output: It should produce at least one output.
  • Definiteness: Every step must be clear.
  • Finiteness: It must terminate after a finite number of steps.
  • Effectiveness: Every step should be practical and executable.
Algorithm – Addition of Two Numbers
  1. Start
  2. Input A and B
  3. Calculate SUM = A + B
  4. Display SUM
  5. Stop
SLIDE 05

📊 Flowchart

A flowchart is a graphical representation of an algorithm. It uses standard symbols to represent different operations.

Important Flowchart Symbols

Symbol Name Purpose
Oval Terminator Start / Stop
Parallelogram Input / Output Taking input or displaying output
Rectangle Process Calculation or processing
Diamond Decision Checking a condition
Arrow Flow Line Shows direction of execution
Exam Tip: Flowchart symbols are frequently asked in short-answer and theory questions.
SLIDE 06

✍️ Pseudocode

Pseudocode is an English-like description of the steps required to solve a problem.

It does not follow the exact syntax of any programming language.

Pseudocode – Addition
``` 
START

INPUT A, B

SUM = A + B

PRINT SUM

STOP
```

Advantages

  • Easy to understand.
  • Language independent.
  • Helps before writing actual code.
  • Makes program logic clear.
SLIDE 07

🔨 Stepwise Refinement

Stepwise refinement is a problem-solving technique in which a large problem is divided into smaller and simpler tasks.

Example – Student Result System
  1. Take student marks.
  2. Calculate total marks.
  3. Calculate percentage.
  4. Determine grade.
  5. Display result.
Benefit: Complex problems become easier to design, code, test and maintain.
SLIDE 08

🐞 Debugging and Testing

Debugging

Debugging is the process of finding and removing errors from a program.

Testing

Testing means executing a program with different inputs to check whether it produces the expected output.

Types of Common Errors

Error Meaning Example
Syntax Error Violation of language rules. Missing semicolon
Runtime Error Error during execution. Division by zero
Logical Error Program runs but gives wrong result. Wrong formula
SLIDE 09

⏱️ Time and Space Complexity

Time Complexity

Time complexity describes how the running time of an algorithm grows as the input size increases.

Space Complexity

Space complexity describes how much additional memory an algorithm requires.

Common Complexities

Complexity Name
O(1) Constant
O(log n) Logarithmic
O(n) Linear
O(n²) Quadratic
SLIDE 10

⌨️ Basic Input and Output in C

C provides standard input and output functions through the stdio.h header file.

printf()

Used to display output on the screen.

scanf()

Used to take input from the user.

``` 
#include <stdio.h>

int main()
{
    int a;

    printf("Enter a number: ");
    scanf("%d", &a);

    printf("Number = %d", a);

    return 0;
}
```
OUTPUT
``` 
Enter a number: 10
Number = 10
```
SLIDE 11

🔍 Tracing and Dry Run

A dry run means manually executing a program step by step without actually running it on a computer.

Example

``` 
int a = 5;
int b = 3;
int sum = a + b;
```
Variable Value
a 5
b 3
sum 8
Result: SUM = 5 + 3 = 8
SLIDE 12

💻 Introduction to C

C is a general-purpose, procedural and structured programming language.

C was developed by Dennis Ritchie at Bell Labs in the early 1970s.

Features of C

  • Simple and efficient
  • Fast execution
  • Portable
  • Structured programming support
  • Middle-level language
  • Pointer support
  • Rich set of operators
  • Large standard library

Applications of C

  • Operating systems
  • Embedded systems
  • Compilers
  • System software
  • Drivers
  • Games and applications
SLIDE 13

🔤 High-Level vs Low-Level Language

High-Level Language Low-Level Language
Easy for humans to understand. Closer to hardware.
More readable. More difficult to understand.
Generally more portable. More machine dependent.
Examples: C, C++, Java. Examples: Assembly, Machine language.
Note: C is commonly described as a middle-level language because it provides both high-level programming constructs and low-level memory/hardware-oriented features.
SLIDE 14

⚙️ Translators

A translator converts a program written in one language into another form that can be executed by the computer.

Translator Function
Compiler Translates the source program into machine/object code.
Interpreter Translates and executes instructions one by one.
Assembler Converts assembly language into machine code.
Exam Question: Differentiate compiler, interpreter and assembler.
SLIDE 15

🧱 Structure of a C Program

``` 
#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}
```

Explanation

  1. #include <stdio.h> – Includes the standard input/output header.
  2. int main() – Main function from where program execution begins.
  3. printf() – Displays output.
  4. return 0; – Indicates successful program termination.
SLIDE 16

📐 Syntax and Semantics

Syntax

Syntax means the grammatical rules used to write a program correctly.

Syntax Error Example
``` 
printf("Hello")
```

The semicolon is missing.

Semantics

Semantics refers to the meaning of a statement or program.

Remember: Syntax = How the statement is written.
Semantics = What the statement means.
SLIDE 17

🧠 Memory Layout of a C Program

A running C program uses different areas of memory.

Memory Area Purpose
Text / Code Contains executable program instructions.
Data Stores initialized global and static variables.
BSS Stores uninitialized global and static variables.
Heap Used for dynamic memory allocation.
Stack Stores function calls and local variables.
Important: Stack and heap are especially important when studying functions, pointers and dynamic memory.
