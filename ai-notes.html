UNIT 1 • FOUNDATIONS

📘 Foundations of Artificial Intelligence

Introduction, evolution, types, domains, characteristics and applications of AI.

1. What is Artificial Intelligence?

Definition: Artificial Intelligence is a branch of computer science that focuses on creating machines and computer systems capable of performing tasks that normally require human intelligence.

AI systems can perform tasks such as learning, reasoning, problem solving, decision making, language understanding, perception and pattern recognition.

2. Characteristics of AI

🧠

Learning

Ability to learn patterns from data and experience.

🔍

Reasoning

Ability to use logic and available information.

🎯

Decision Making

Selecting suitable actions based on information.

👁️

Perception

Understanding images, sounds and environmental input.

💬

Language

Processing and understanding human language.

⚙️

Automation

Performing tasks with reduced human intervention.

3. Evolution of Artificial Intelligence

  • 1950s: Early research on machine intelligence began.
  • 1956: The Dartmouth workshop helped establish AI as a field of research.
  • 1960s–1970s: Early problem-solving programs and language systems were developed.
  • 1980s: Expert systems became popular.
  • 1990s–2000s: Machine learning became increasingly important.
  • 2010s: Deep learning achieved major improvements in image, speech and language tasks.
  • Today: AI is widely used in healthcare, education, finance, transportation, agriculture and entertainment.

4. Types of Artificial Intelligence

A. Based on Capability

🎯

Narrow AI

Designed to perform a specific task or a limited group of tasks.

Example: recommendation systems and voice assistants.

🧠

General AI

A theoretical AI capable of performing a broad range of intellectual tasks.

🚀

Super AI

A hypothetical form of AI that would exceed human intelligence across many areas.

B. Based on Functionality

  1. Reactive Machines: Respond only to current input.
  2. Limited Memory: Uses past information for a limited purpose.
  3. Theory of Mind: A theoretical concept involving understanding emotions and intentions.
  4. Self-Aware AI: A hypothetical AI possessing self-awareness.

5. Major Domains of AI

💬

Natural Language Processing

Enables computers to process and understand human language.

Examples: chatbots, translation and speech systems.

👁️

Computer Vision

Enables computers to understand images and videos.

Examples: face recognition and object detection.

🧑‍⚕️

Expert Systems

Uses stored knowledge and rules to solve domain-specific problems.

6. AI vs Machine Learning vs Deep Learning

Feature AI Machine Learning Deep Learning
Meaning Broad field of intelligent systems Subset of AI Subset of ML
Main idea Make machines intelligent Learn patterns from data Learn using deep neural networks
Data requirement May or may not require data Usually requires data Often requires large datasets
Artificial Intelligence ↓ Machine Learning ↓ Deep Learning

7. Applications of AI

  • Healthcare: Medical image analysis and decision support.
  • Education: Personalized learning and automated assistance.
  • Finance: Fraud detection and risk analysis.
  • Agriculture: Crop monitoring and smart farming.
  • Transportation: Navigation and autonomous systems.
  • Entertainment: Content and recommendation systems.

UNIT 2 • SEARCH & KNOWLEDGE

📗 Searching Algorithms & Knowledge Representation

Search strategies, BFS, DFS, heuristic search and methods of representing knowledge.

1. Searching for Solutions

Searching is the process of finding a sequence of actions that transforms an initial state into a desired goal state.
Initial State ↓ Possible Actions ↓ Search Space ↓ Search Strategy ↓ Goal State

2. Breadth First Search (BFS)

BFS explores nodes level by level. It first visits all neighbouring nodes before moving to the next level.

BFS generally uses a Queue data structure.

A / \ B C / \ / \ D E F G BFS: A → B → C → D → E → F → G
Example
If we want to find a nearby node in an unweighted graph, BFS explores the graph level by level.

3. Depth First Search (DFS)

DFS explores one branch as deeply as possible before returning and exploring another branch.

DFS uses a Stack or recursion.

A / \ B C / \ / \ D E F G DFS: A → B → D → E → C → F → G

4. BFS vs DFS

Feature BFS DFS
Traversal Level by level Depth first
Data structure Queue Stack / Recursion
Memory Usually higher Usually lower
Shortest path Can find shortest path in an unweighted graph Does not generally guarantee shortest path

5. Data-Driven and Goal-Driven Search

📊

Data-Driven Search

Starts with available facts or data and moves toward a desired conclusion.

🎯

Goal-Driven Search

Starts with the goal and works backward to determine the required facts or actions.

6. Heuristic Search

Heuristic search uses additional problem-specific knowledge to guide the search toward promising solutions.

A heuristic function provides an estimate of how close a state is to the goal.
Example: Route Finding
If a car has to travel from City A to City B, estimated distance to City B can help select a promising route.

7. Knowledge Representation

Knowledge Representation is the process of storing information in a form that an AI system can use for reasoning and problem solving.

Propositional Calculus

Represents statements as true or false.

Predicate Calculus

Represents objects, properties and relationships.

Production Systems

Represents knowledge using IF-THEN rules.

Semantic Networks

Represents concepts and relationships as graphs.

Frames

Stores structured information using slots and values.

Scripts

Represents a sequence of events in a situation.

8. Propositional Calculus

Propositional calculus works with propositions or statements that have a truth value: True or False.

P = "It is raining."

Q = "The road is wet."

P → Q

9. Predicate Calculus

Predicate calculus represents objects, their properties and relationships using predicates and variables.

Human(Nitin)

This means that Nitin is a human.

10. Unification

Unification is the process of finding substitutions that make two logical expressions identical.

Student(x)

Student(Nitin)

Therefore: x = Nitin

11. Resolution

Resolution is a rule of inference used to derive new conclusions from logical statements. It is widely used in automated reasoning.

12. Production System

A production system represents knowledge using IF-THEN rules.

IF temperature is high
THEN turn ON the fan.

Main components include:

  • Rule set
  • Working memory
  • Control strategy

13. Semantic Network

A semantic network represents concepts using nodes and relationships using links.

Animal ↓ IS-A ↓ Dog ↓ HAS ↓ Tail

14. Conceptual Graph

A conceptual graph represents concepts and relationships using a graph structure.

Person → drives → Car

15. Frames

A frame is a structured representation containing information about an object or concept.

Frame: Student

Name → Nitin
Course → B.Tech CSE
Semester → 1st

16. Scripts

A script represents a normal sequence of events in a particular situation.

Restaurant Script
  1. Enter restaurant
  2. Choose table
  3. Order food
  4. Eat food
  5. Pay bill
  6. Leave restaurant

⭐ Exam Focus

BFS, DFS, heuristic search, knowledge representation, propositional calculus, predicate calculus, unification, resolution, production systems, semantic networks, frames and scripts are important topics.

UNIT 3 • EXPERT SYSTEMS

📙 Expert Systems

Concepts, architecture, components, knowledge engineering and applications.

1. What is an Expert System?

An Expert System is an AI-based computer system that uses stored knowledge and reasoning methods to solve problems in a specific domain.

It attempts to provide solutions similar to those provided by a human expert.

2. Components of Expert System

🗄️

Knowledge Base

Stores facts, rules and domain-specific knowledge.

⚙️

Inference Engine

Applies rules to available knowledge to derive conclusions.

🖥️

User Interface

Allows users to communicate with the expert system.

🧠

Working Memory

Stores information related to the current problem.

3. Structure of Expert System

USER ↓ User Interface ↓ Inference Engine ↙ ↘ Knowledge Working Base Memory ↓ Solution

4. Architecture of Expert System

Domain Expert ↓ Knowledge Engineer ↓ Knowledge Base ↓ Inference Engine ↓ User Interface ↓ User

5. Human Element in Expert Systems

  • Domain Expert: Provides specialized knowledge.
  • Knowledge Engineer: Collects and represents expert knowledge.
  • User: Uses the system to obtain advice or solutions.
  • Developer: Develops and maintains the software.

6. Knowledge Engineering

Knowledge Engineering is the process of collecting, organizing, representing and maintaining knowledge for an AI system.

Knowledge Acquisition ↓ Knowledge Representation ↓ Knowledge Storage ↓ Inference ↓ Decision / Solution

7. Knowledge Acquisition

Knowledge acquisition is the process of obtaining knowledge from experts, documents, databases and other sources.

Methods

  • Interviews
  • Observation
  • Questionnaires
  • Document analysis
  • Data analysis

8. Difficulties in Knowledge Acquisition

  • Experts may find it difficult to explain their knowledge.
  • Knowledge may be incomplete.
  • Knowledge may change with time.
  • Different experts may have different opinions.
  • Knowledge collection can be expensive and time-consuming.

9. Problem Areas of Expert Systems

🏥

Medical Diagnosis

Assists in analysing symptoms and possible diseases.

💰

Finance

Supports financial analysis and risk assessment.

🔧

Equipment Diagnosis

Helps identify faults in machines and equipment.

📞

Customer Support

Provides automated assistance and troubleshooting.

10. Types of Expert Systems

  1. Rule-Based Expert Systems
  2. Frame-Based Expert Systems
  3. Fuzzy Expert Systems
  4. Case-Based Reasoning Systems
  5. Neural Expert Systems

11. Success Factors

  • High-quality knowledge
  • Accurate rules
  • Suitable problem domain
  • Reliable inference mechanism
  • Good user interface
  • Proper maintenance

⭐ Exam Focus

Definition of expert system, components, architecture, knowledge base, inference engine, knowledge acquisition, knowledge engineering and applications are important examination topics.

UNIT 4 • MACHINE LEARNING

📕 Introduction to Machine Learning Concepts

ML fundamentals, categories, workflow, applications and learning techniques.

1. What is Machine Learning?

Machine Learning is a branch of AI that enables computers to learn patterns from data and improve their performance without requiring explicit programming for every task.

2. Significance of Machine Learning

  • Automates decision making.
  • Finds useful patterns in data.
  • Helps make predictions.
  • Improves systems using experience and data.
  • Supports intelligent applications.
  • Can process large datasets efficiently.

3. Categories of Machine Learning

👨‍🏫

Supervised Learning

Learns from labelled data where the desired output is known.

Examples: Classification and Regression.

🔎

Unsupervised Learning

Finds hidden patterns in unlabelled data.

Examples: Clustering and Association.

🎮

Reinforcement Learning

An agent learns by interacting with an environment using rewards and penalties.

MACHINE LEARNING | ------------------------- | | | Supervised Unsupervised Reinforcement | | | Labelled Unlabelled Reward / Data Data Penalty

4. Machine Learning Workflow

Collect Data ↓ Clean Data ↓ Prepare Data ↓ Select Features ↓ Select Model ↓ Train Model ↓ Test Model ↓ Evaluate Model ↓ Deploy Model ↓ Monitor & Improve

5. Classification

Classification is a supervised learning technique used to assign data into predefined categories.

Example
Email → Spam / Not Spam

The output is a category.

6. Regression

Regression is a supervised learning technique used to predict continuous numerical values.

Example
House Area + Location → Predicted House Price

7. Clustering

Clustering is an unsupervised learning technique that groups similar data objects together.

Example
Customers
↓
Group 1 • Group 2 • Group 3

based on similar purchasing behaviour.

8. Association

Association learning discovers relationships between different items in a dataset.

Example
Customers who buy Bread may also buy Butter.

9. Supervised vs Unsupervised Learning

Feature Supervised Unsupervised
Data Labelled Unlabelled
Output Known Not predefined
Examples Classification, Regression Clustering, Association

10. Reinforcement Learning

Reinforcement Learning is a learning method where an agent interacts with an environment and learns from rewards and penalties.

Environment ↓ State ↓ Agent ↓ Action ↓ Reward ↓ Learning ↓ Better Action

The objective is to learn a strategy that maximizes the total reward over time.

11. Applications of Machine Learning

🎬

Recommendation

Movie, music and product recommendations.

📧

Spam Detection

Identifies unwanted or suspicious messages.

🏦

Fraud Detection

Identifies unusual financial transactions.

🏥

Healthcare

Supports diagnosis and prediction tasks.

12. Machine Learning Model Lifecycle

  1. Define the problem.
  2. Collect relevant data.
  3. Clean and prepare data.
  4. Select an appropriate algorithm.
  5. Train the model.
  6. Evaluate the model.
  7. Deploy the model.
  8. Monitor and improve the model.
