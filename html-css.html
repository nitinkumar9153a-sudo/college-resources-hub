1. Introduction to Web Technology

Write a simple webpage to introduce Web, Internet, Browser, WordPress, HTML, Web Server and HTTP Protocol.

💻 Simple Code

<html>

<head>
    <title>Web Technology</title>
</head>

<body>

<p>HTML is used to create webpages.</p>

<p>Web Server stores web pages.</p>

<p>HTTP is used for communication.</p>

<p>WordPress is used to create websites.</p>

</body>

</html>

Browser is used to open websites.

HTML is used to create webpages.

Web Server stores web pages.

HTTP is used for communication.

4. Image Map of India

Create a webpage to display the map of India and link different states using image map.

💻 Simple Code 
<!DOCTYPE html>
<html>

<body>

<h2>Map of India</h2>

<img src="india-map.jpg"
     width="600"
     usemap="#india">

<map name="india">

    <area shape="rect"
          coords="182,211,229,221"
          href="haryana.html">

    <area shape="rect"
          coords="390,260,460,310"
          href="bihar.html">

    <area shape="rect"
          coords="230,120,280,165"
          href="punjab.html">

    <area shape="rect"
          coords="100,180,180,260"
          href="rajasthan.html">

</map>

</body>

</html>
👀 Output

Map of India

India map will be displayed here.

Clicking a selected state will open its respective webpage.

6. Frameset with Three Sections

💻 Simple Code

<html>

    <frame src="title.html">

    <frame src="display.html">

    <frame src="menu.html">

</frameset>

</html>

⚡ Quick Revision

HTML: HyperText Markup Language

HTTP: HyperText Transfer Protocol

Browser: Software used to access websites.

Web Server: Stores and provides web pages.

Tag: HTML instruction written inside < >.

Attribute: Gives extra information about a tag.

Link: Created using <a> tag.

href: Specifies the destination of a link.

Image: Added using <img> tag.

CSS: Used to style HTML webpages.

Inline CSS: CSS written inside the HTML tag.

Internal CSS: CSS written inside <style>.

External CSS: CSS written in a separate CSS file.
