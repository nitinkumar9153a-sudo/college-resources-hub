📚 AI & ML PYQs

Previous-question style practice for examination

📘 Unit 1: Foundations of AI

Q1. Define Artificial Intelligence. Explain its applications.

Answer:

Artificial Intelligence is a branch of computer science that enables machines to perform tasks requiring human intelligence.

Applications:

  • Healthcare
  • Agriculture
  • Finance
  • Smart Cities
  • Education

Q2. Explain the types of Artificial Intelligence.

Answer:
  • Narrow AI: Performs a specific task.
  • General AI: Theoretical AI capable of performing a wide range of intellectual tasks.
  • Super AI: Hypothetical AI exceeding human intelligence across many areas.

Q3. Differentiate between AI, Machine Learning and Deep Learning.

Answer:

AI is the broad field of intelligent machines. Machine Learning is a subset of AI that learns patterns from data. Deep Learning is a subset of Machine Learning based on multi-layer neural networks.

AI ↓ Machine Learning ↓ Deep Learning

Q4. Explain Natural Language Processing and Computer Vision.

NLP: Enables computers to understand and process human language.

Computer Vision: Enables computers to analyse images and videos.

Q5. Explain the characteristics of intelligent systems.

Answer:
  • Learning
  • Reasoning
  • Problem solving
  • Decision making
  • Adaptability
  • Perception

📗 Unit 2: Searching Algorithms & Knowledge Representation

Q6. What is Breadth First Search (BFS)?

Answer:

BFS is an uninformed search algorithm that explores nodes level by level.

It generally uses a queue.

A / \ B C / \ / \ D E F G BFS: A → B → C → D → E → F → G

Q7. What is Depth First Search (DFS)?

Answer:

DFS explores one branch as deeply as possible before backtracking.

It can use a stack or recursion.

Q8. Differentiate between BFS and DFS.

  • BFS: Searches level by level.
  • DFS: Searches depth-wise.
  • BFS: Uses a queue.
  • DFS: Uses a stack or recursion.

Q9. What is heuristic search?

Answer:

Heuristic search uses additional problem-specific information to guide the search towards a promising solution.

This additional information is called a heuristic.

Q10. What is Knowledge Representation?

Answer:

Knowledge Representation is the process of storing knowledge in a form that a computer can use for reasoning and problem solving.

Examples:

  • Propositional Calculus
  • Predicate Calculus
  • Semantic Networks
  • Frames
  • Production Systems

Q11. Explain Production System.

Answer:

A production system represents knowledge using IF-THEN rules.

IF condition is true ↓ THEN action

Example: IF temperature is high THEN turn ON the fan.

Q12. Explain Semantic Network with example.

Answer:

A semantic network represents knowledge using nodes and links showing relationships.

Animal ↓ IS-A ↓ Dog ↓ HAS ↓ Tail

📙 Unit 3: Expert Systems

Q13. What is an Expert System?

Answer:

An Expert System is an AI-based system that uses knowledge and reasoning techniques to solve problems in a specific domain.

Q14. Explain the architecture of an Expert System.

Answer:
USER ↓ User Interface ↓ Inference Engine ↙ ↘ Knowledge Base Working Memory ↓ Solution

Q15. Explain the components of an Expert System.

  • Knowledge Base: Stores facts and rules.
  • Inference Engine: Applies rules and derives conclusions.
  • User Interface: Provides communication with the user.
  • Working Memory: Stores information related to the current problem.

Q16. What is Knowledge Engineering?

Answer:

Knowledge Engineering is the process of collecting, organizing, representing and maintaining knowledge for an AI or expert system.

Q17. Explain Knowledge Acquisition and its difficulties.

Answer:

Knowledge Acquisition is the process of obtaining knowledge from experts, documents, databases and other sources.

Difficulties:

  • Experts may find knowledge difficult to explain.
  • Knowledge may be incomplete.
  • Knowledge may change with time.
  • Different experts may provide different information.

📕 Unit 4: Machine Learning Concepts

Q18. Define Machine Learning and explain its significance.

Answer:

Machine Learning is a branch of AI that enables computers to learn patterns from data and improve their performance.

Significance:

  • Automation
  • Prediction
  • Pattern recognition
  • Data analysis
  • Intelligent decision making

Q19. Explain the three categories of Machine Learning.

  • Supervised Learning: Learns from labelled data.
  • Unsupervised Learning: Finds patterns in unlabelled data.
  • Reinforcement Learning: Learns using rewards and penalties.

Q20. Explain the Machine Learning workflow.

Collect Data ↓ Clean Data ↓ Prepare Data ↓ Select Model ↓ Train Model ↓ Test Model ↓ Evaluate Model ↓ Deploy Model

Q21. What is Classification? Give an example.

Answer:

Classification is a supervised learning technique that assigns data into predefined categories.

Example: Email → Spam / Not Spam

Q22. What is Regression? Give an example.

Answer:

Regression is a supervised learning technique used to predict continuous numerical values.

Example: Predicting the price of a house.

Q23. What is Clustering?

Answer:

Clustering is an unsupervised learning technique that groups similar data items together.

Example: Grouping customers based on purchasing behaviour.

Q24. Explain Reinforcement Learning.

Answer:

Reinforcement Learning is a type of Machine Learning in which an agent learns by interacting with an environment.

The agent receives rewards for desirable actions and penalties for undesirable actions.

Agent ↓ Action ↓ Environment ↓ Reward ↓ Learning

Q25. Differentiate between Classification and Regression.

  • Classification: Predicts categories or classes.
  • Regression: Predicts continuous numerical values.

Classification Example: Spam / Not Spam

Regression Example: House Price Prediction
