Links and Images

What is a Link?

A link is used to connect one web page to another web page.

Anchor Tag

The <a> tag is used to create a hyperlink.

Syntax

<a href="page.html">Click Here</a>

Example

Go to Home Page

What is an Image?

The <img> tag is used to display an image on a web page.

Syntax

<img src="student.jpg" width="200" height="200">

Important Image Attributes

  • src: Specifies the image location.
  • width: Specifies the width of the image.
  • height: Specifies the height of the image.
  • alt: Provides alternative text for the image.
