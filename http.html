HTTP

What is HTTP?

HTTP stands for HyperText Transfer Protocol. It is used for communication between a web browser and a web server.

How HTTP Works?

  1. User enters a website address in the browser.
  2. Browser sends a request to the server.
  3. Server processes the request.
  4. Server sends a response to the browser.
  5. Browser displays the web page.

Example

Browser → Request → Server

Browser ← Response ← Server

Full Form

HTTP = HyperText Transfer Protocol
